# LogiMetrics – Shipment, Revenue & Profitability Analytics

## Project Overview
LogiMetrics is an Excel-based logistics and supply chain analytics project developed to examine shipment operations, transportation performance, delivery status, revenue and profitability. The project uses shipment-level data to identify operational patterns and evaluate key business performance indicators.

![logimetrics-dashboard](./Screenshot%20(378).png)

## Project Objectives
- Analyze shipment and delivery performance.
- Compare revenue and profitability across transportation modes.
- Examine delivery status, delays and on-time performance.
- Analyze shipping costs and cost per kilometre.
- Evaluate performance across product categories, carriers and routes.

## Dataset Overview
- **Total Records:** 2,000 shipment records
- **Total Columns:** 24
- **Data Type:** Shipment and logistics operational data

The dataset includes shipment IDs, origin and destination cities, transportation modes, carriers, warehouses, product categories, shipping costs, delivery dates, revenue and profit.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Data Analysis
- Dashboard Development
- Data Visualization

## Key Analysis Areas
1. Transportation Mode Analysis
2. Monthly Revenue Analysis
3. Delivery Status Analysis
4. Product Category Profitability
5. Route-wise Revenue Analysis
6. Shipment and Delivery Performance

## Key Performance Indicators
- Total Revenue
- Total Profit
- Shipping Cost
- Delivery Time
- On-Time Delivery
- Cost per Kilometre

## Project Files
- `Logistics & Supply Chain Performance Dashboard.xlsx` – Excel workbook containing the dashboard, source data and supporting Pivot Table calculations.

## Project Outcome
Developed an interactive Excel dashboard to present logistics and supply chain performance indicators and support data-driven operational analysis.

## Limitations
This project is based on the available dataset. The findings reflect the records included in the workbook and should not be interpreted as actual performance figures for a real logistics company.
